# Mezgeb UI Revamp Changes

## Design System & Global Shell
- **Tokens & Fonts (`index.html`, `src/styles/tokens.css`, `src/index.css`)**: Added CSS design tokens (`--paper`, `--stone`, `--sand`, `--mint`, `--ink`, `--muted`, `--night`, `--line`, `--accent`, `--accent-soft`, `--ok`, `--warn`, `--error`, `--shadow-float`), `.mezgeb-hc` pure black-on-white 2px-border high-contrast theme, `prefers-reduced-motion` handling, Inter + Noto Sans Ethiopic font loading, and `3px solid var(--accent)` focus outlines with `scroll-margin-top` for sticky headers.
- **Shared Primitives (`src/ui/`)**: Built `Button` (44px/48px touch targets, loading label, `disabledReason`), `Field` (always-visible `<label>`, hint, error alert, `inputRef`/`textareaRef`), `VoiceButton` (idle/listening/review/failed), `ReadAloudButton`, `ChoiceList`, `Progress`, `Banner`, `Toast`, `Dialog`, `Tabs`, `CodeBlock`, `Table`, `Badge`, `EmptyState`, `Skeleton`, `QuestionIcon`, `SiteHeader` (`#main` skip link, `EN`/`አማ` toggle, 6 nav items, accessible mobile drawer), and `SiteFooter` (`--night` rounded top block, 3 link columns, Apache-2.0 licence, source link, Digital Bridge Accessibility Hackathon 2026 credit).
- **Layout (`src/components/Layout.tsx`)**: Updated `<main id="main">` landmark using `SiteHeader` and `SiteFooter`.

## Learner Widget (`src/components/MezgebWidget.tsx`)
- Added **Welcome** screen (language rows `አማርኛ` / `English`, `Start`, and `I have a saved link` resume control) and **How do you want to answer?** mode selector (`Speak and listen`, `Read and type`, `Simple words with pictures`) with top-bar mode switching and optional auto-read in simple mode.
- Switched Date of Birth to three plain `<select>` controls (Ethiopian months first in Amharic mode, converting underneath to `That is …`), added `Other document` camera/photo upload controls, defaulted Support sharing to OFF with explicit status text, added bottom-sheet / side-panel Help drawer, added `highContrast`, `assistedMode`, `onEvent` (`step.completed`, `registration.completed`), and all 8 `demoTrigger` preview states.
